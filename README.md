# Project 2: Dataset Analyzer

## Description
A beginner-friendly Python data analysis project that loads a CSV file and automatically summarizes its contents.

## Features
- Counts rows and columns
- Detects missing values
- Identifies numerical columns
- Identifies categorical columns
- Displays basic statistical summaries

## Technologies
- Python
- Pandas
- Miniconda

## How to Run
1. Activate the environment: `conda activate project2`
2. Install dependencies: `pip install -r requirements.txt`
3. Place a CSV file in the `data` folder.
4. Run: `python analyzer.py`
